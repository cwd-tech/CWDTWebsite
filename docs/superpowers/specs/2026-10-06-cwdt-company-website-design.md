# CWDT 澄叡公司官網設計規格

## 目標

建立 CWDT 澄叡公司的繁體中文單頁形象官網。首頁先提供可替換的文案占位內容，之後由公司提供正式文案與聯絡資料。初版以 GitHub Pages 靜態託管為目標，支援日後設定自訂網域。

## 設計方向

Expetech 佳研智聯首頁是目前主要的視覺參考：以滿版影像主視覺開場，使用精簡導覽，再用大幅情境圖搭配服務介紹、案例、公司介紹與聯絡資訊；頁面在明亮和深色區塊間轉換。Billing 首頁只保留為最初的次要參考。

CWDT 網站只借鑑一般版面節奏與影像敘事方式，不複製參考網站的文字、標誌、圖片或其他品牌素材。CWDT 自身尚未提供的業務敘述、服務、案例、標誌與聯絡資料都以可辨識的待補占位呈現，不猜測公司事實。

視覺基調使用深色主視覺、藍綠科技色點綴、明亮內容區與大型圖片位置。主視覺先以專案自有樣式與中性占位素材呈現，正式照片或影片日後可替換。避免把外部參考網站的遠端媒體作為執行期依賴。

## 資訊架構與互動

單頁內容依序包含：

1. 頂部品牌識別與導覽。
2. 滿版主視覺、待補標題／簡介，以及導向服務或聯絡區的主要按鈕。
3. 關於 CWDT 的介紹區。
4. 服務項目圖文區。
5. 合作案例區。
6. 聯絡資訊區。
7. 頁尾與頁內導覽。

導覽使用頁面錨點，不使用額外頁面路由。桌機顯示精簡導覽；窄螢幕導覽收合，並可由鍵盤操作。頁面以實景或中性占位圖搭配文字敘事，部分區段使用深色背景，其餘保持明亮和充足留白。

聯絡區只呈現公司提供的聯絡資訊，不加入表單或任何資料收集功能。Email 與電話在取得正式資料後可成為 `mailto:`／`tel:` 連結。初版不含後端 API、資料庫、登入、分析追蹤或第三方表單服務。

## 技術架構

- 前端：React、TypeScript、Vite。
- 輸出：Vite 建置的靜態檔案；不使用伺服器端執行期。
- 頁面：單一首頁，以語意化區段與錨點導覽組成。
- 內容：將占位文案與聯絡欄位集中在清楚的位置，方便日後替換；服務和案例使用資料驅動的卡片呈現。
- 樣式與媒體：專案自有 CSS 與本地資產；主視覺及圖片區在正式素材到位前使用中性占位內容。

## 部署與網域

GitHub Actions 在程式推送後安裝相依套件、建置 Vite 專案，並將靜態輸出部署至 GitHub Pages。單頁以錨點跳轉，因此不需要為多頁 SPA 路由設定伺服器 fallback。

GitHub Pages 可使用自訂網域；正式網域尚未提供，所以規格不固定寫入任何網域或 DNS 值。設定網域時須在 GitHub Pages 專案設定與網域 DNS 設定中配合完成；根網域與 `www` 子網域所需記錄不同。實際 DNS 變更待網域與託管商資料確定後處理。DNS 操作與發布到 GitHub 帳戶不屬於本地網站初版的自動化範圍。

## 無障礙、搜尋與韌性

- 使用單一主要標題、正確的標題層級、語意化導覽與區段標籤。
- 鍵盤可以操作所有導覽和按鈕，並提供清楚的焦點樣式。
- 有意義的圖片提供替代文字；純裝飾圖片使用空替代文字。
- 設定繁體中文文件語系及可替換的頁面標題、描述等基本 metadata。
- 本地圖片載入失敗時仍保留背景色與文字對比；主視覺以 CSS 底色作為 fallback。
- 不在沒有資料處理能力的情況下顯示可送出的聯絡表單。

## 驗收條件

- `npm run build` 可產生可供靜態託管的 `dist/`。
- 頁面以桌機及手機寬度呈現時，導覽、文字、服務／案例區與聯絡資料皆保持可讀且不溢出。
- 導覽項目能正確跳至對應首頁區段；手機導覽能以滑鼠與鍵盤操作。
- 佔位內容、圖片與聯絡欄位易於替換，不含虛構的公司事實或參考網站素材。
- GitHub Actions 流程能以建置輸出作為 GitHub Pages 發布來源。

## 初版不包含

- 多頁路由、後端服務、資料庫、登入或管理介面。
- 聯絡表單、表單服務串接或個人資料收集。
- 未經 CWDT 確認的服務文案、案例、公司地址、電話、Email、品牌標誌或官方網域。
- GitHub 帳戶中的儲存庫建立、遠端推送、Pages 設定，以及網域 DNS 變更。
